# Homebrew tap for Flipic Lens

[Flipic Lens](https://flipic.app) is a free, open-source photo viewer and culling tool for the Mac. Source: [xmasdong/flipic](https://github.com/xmasdong/flipic).

```sh
brew install --cask xmasdong/flipic/flipic-lens
```

Update with `brew upgrade --cask flipic-lens`, or let the app update itself.
